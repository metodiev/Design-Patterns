# Gang of Four (GoF)

Who are the “Gang of Four”?
Authors of one of the best book for Design Patterns: Design Patterns: Elements of Reusable Object-Oriented Software


The Gang of Four (GoF) are the four authors of that book:

- Erich Gamma
- Richard Helm
- Ralph Johnson
- John Vlissides

## Why They Matter

Before this book (1994), developers: Re-invented solutions repeatedly, had no common vocabulary

The GoF:

- Standardized 23 core design patterns
- Gave them names like:
- Builder
- Factory
- Singleton
- Observer

## The 3 categories of GoF Patterns

1. Creational
- Builder 
- Singleton
- Factory Method
- Abstract Factory
- Prototype

2. Structural
- Adapter
- Decorator
- Facade
- Composite
- Proxy

3. Behavioral
- Observer
- Strategy
- Command
- Iterator
- State

## Simple Mental Model
- Need flexible object creation → Builder
- Need interchangeable behavior → Strategy
- Need decoupled communication → Observer
- Need simplified API → Facade
